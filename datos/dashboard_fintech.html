Régimen Tributario

Retención en la fuente sobre rendimientos financieros del 4.0% (Estatuto Tributario Art. 395). Se descuenta de forma periódica sobre los intereses brutos causados.

Trazabilidad de Datos

Todos los resultados son calculados en tiempo real mediante funciones matemáticas puras (sin valores digitados fijos). Verificaciones con tolerancia < 10⁻⁶.

Fórmulas Empleadas en el Motor Financiero

Interés Simple
VF = VP * (1 + i * n)
n = (VF - VP) / (VP * i)
i = (VF - VP) / (VP * n)
Interés Compuesto
VF = VP * (1 + i)^n
VP = VF / (1 + i)^n
n = ln(VF / VP) / ln(1 + i)
Equivalencia & Fisher
EA = (1 + i_p)^m - 1
i_v = i_a / (1 - i_a)
(1 + i_comb) = (1 + IPC)*(1 + sp)
Series Uniformes (Vencida)
VP = A * [(1 - (1+i)^-n) / i]
VF = A * [((1+i)^n - 1) / i]
A = VP * [i / (1 - (1+i)^-n)]
Gradiente Aritmético
VP = VP_base ± (G/i)*[a_n - n/(1+i)^n]
A_eq = VP * [i / (1 - (1+i)^-n)]
Amortización Francés / Alemán
I_t = Saldo_(t-1) * i
Francés: Cuota cte, Abono = A - I_t
Alemán: Abono = Saldo_0 / n cte
